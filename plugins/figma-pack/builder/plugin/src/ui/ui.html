Компоненты кита

Плагин ищет Button, Input, Badge, Avatar, Checkbox и другие по имени и ставит их экземпляры. Чего нет — рисует сам, тоже на токенах.

Контракты компонентов

Контракт — JSON компонента: части, свойства, какой токен на каком свойстве. Из него плагин собирает компонент в Figma, а генератор — React-код. Рисовать руками не нужно.
