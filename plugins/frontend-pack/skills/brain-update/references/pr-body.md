# Описание PR обновления мозга

Собери по шаблону во временный файл и передай `gh pr create --body-file`. Заполняй фактами, пустые разделы пиши как «нет».

```markdown
## Обновление мозга <YYYY-MM-DD>

Источники проверены с <дата из watch-state> по <сегодня>. Новостей: <N>, изменено файлов: <M>.

### Новости и решения

| Источник | Новость | Решение | Файлы |
|---|---|---|---|
| nextjs-blog | [Next.js Security Update …](https://…) | статья | `knowledge/security/…md` |
| tanstack-query | 5.104.5 | ничего | — |

### Решения мейнтейнера

- <библиотека или политика>: что вышло, что предлагаю, ссылка. Без решения ничего не меняю.

### Не проверено

- <id источника>: <причина из brain-watch> (повторить в следующий прогон)

### Метрики

<вывод brain-metrics.mjs как есть: Здоровье, Использование, Предложения>

### Проверки

- `npm test`: <итог>
- `rules/watch-state.json` обновлён: следующий прогон покажет новости после <дата>.

Сливает и выпускает релиз мейнтейнер (`node scripts/release.mjs …`).
```
