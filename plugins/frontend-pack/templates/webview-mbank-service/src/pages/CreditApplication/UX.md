# Заявка на кредит (демо)

- Цель: подать заявку на кредит за минуту. Главное действие: «Продолжить» → код из SMS → «Заявка отправлена».
- Иерархия: шаги → цель → сумма → срок → платёж в месяц → город → комментарий → согласие → кнопка.
- Состояния: отправка (кнопка заблокирована), неверный код (`000000`), проверка кода (лоадер), успех (ResultView), ошибки полей (город, согласие).
- Раскладка: одна колонка, отступы 16px, KeyboardAwarePage (iOS-клавиатура), низ с safe area. API замокано в `useCreditApplicationForm`.
