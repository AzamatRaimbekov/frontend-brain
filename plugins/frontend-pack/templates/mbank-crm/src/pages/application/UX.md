Страница: Заявка на кредит, route /applications/$applicationId
Макет: Figma vVuM5uw3TsWo1xm3vJelXG, frame 35:178 «CRM / Заявка на кредит / Андеррайтинг / 1440» (данные — CL-240118)
Пользователь: андеррайтер; приходит с доски конвейера; цель — проверить заявку и принять решение
Главное действие: «Одобрить кредит» (primary); «Отклонить» (destructive); «Запросить документы» (soft)
Иерархия: 1) номер, статус, сумма, контекст, действия 2) этапы 3) Заёмщик / Параметры / Документы (слева),
          Скоринг и История (справа)
Данные: GET /api/applications/:id → заявка (этапы, заёмщик, кредит, документы, скоринг, история)
Действия: POST /api/applications/:id/decision { decision } → обновлённая заявка | 409 если решение уже есть;
          POST /api/applications/:id/documents-request → обновлённая заявка (новая запись истории)
Состояния: загрузка (скелетон той же геометрии) / не найдена (404 → «Заявка не найдена» + «К конвейеру») /
           ошибка (500 → «Повторить») / проблемный документ (значение красным) / нет скоринга (карточки нет) /
           решение принято (кнопок нет, статус «Одобрена»/«Отказ») / ошибка действия (текст в диалоге, диалог открыт)
Решение: кнопка → AlertDialog «Одобрить кредит?» / «Отклонить заявку?» + последствие → подтверждение (Button со
         спиннером, не AlertDialogAction) / «Отмена» (фокус по умолчанию) → успех: диалог закрывается, статус и
         история из ответа сервера, фокус на h1, объявление через role=status; доска конвейера инвалидируется
Адаптив: 1440 — две колонки (716 + 380); <1024 — одна колонка; 375 — этапы списком, строки «поле — значение»
         в два ряда, кнопки во всю ширину, хлебные крошки — только номер заявки
Доступность: один h1 (номер заявки), h2 у каждой карточки, крошки — nav, этапы — ol с aria-current=step,
             история — ol с <time>
Тексты: lib/messages.ts фичи applications
Демо-режим: ?mock=error — ошибка загрузки; ?mock=action-error — ошибка решения / запроса документов
Допущения: решение принимает «Токтосунов Б.» (авторизации нет); оптимистичного обновления нет — решение
           необратимо (react-ux §4)
